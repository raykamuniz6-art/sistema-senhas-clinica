Sistema de Gerenciamento de Senhas de Atendimento Clínico

1. Apresentação do Projeto

Este projeto consiste no desenvolvimento de um Sistema de Gerenciamento de Senhas de Atendimento Clínico, desenvolvido na linguagem de programação C.

O objetivo é organizar o atendimento de pacientes em uma clínica médica por meio de um sistema de cadastro, classificação automática de prioridades e gerenciamento de filas.

O sistema foi desenvolvido como atividade acadêmica, com o propósito de aplicar conceitos fundamentais de lógica de programação e desenvolvimento de software.

2. Objetivo

Criar uma aplicação que permita cadastrar pacientes, gerar senhas automaticamente e organizar a ordem de atendimento de acordo com as categorias de prioridade estabelecidas na atividade.

3. Funcionalidades do Sistema

O sistema apresenta as seguintes funcionalidades:

Cadastro de pacientes.
Registro do nome e da idade.
Registro do gênero do paciente.
Identificação de gestantes e lactantes.
Identificação de pessoas com necessidades especiais.
Identificação de pessoas com condição de obesidade.
Classificação automática dos pacientes.
Geração de senhas sequenciais.
Consulta da próxima senha.
Chamada do próximo paciente.
Finalização do atendimento.
Exibição do painel de chamadas.
Consulta da quantidade de pacientes em espera.
4. Categorias de Atendimento

O sistema trabalha com três categorias de atendimento:

4.1 Urgente (U)

Pacientes com idade superior a 80 anos.
